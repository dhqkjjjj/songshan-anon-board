【松農匿名投稿板 官方管理規範】

本平台旨在提供校園師生自由、多元的表達管道，維護友善且負責任的網路社群環境。所有投稿者請務必仔細閱讀並遵守以下規範：

  1. 貼文審核與發布時間：
    投稿送出後需經過版主與系統進行人工審核，貼文大概需要 1 至 7 個工作天 完成審核並公開發布，請耐性等待，勿急於重複投稿。
  2. 嚴禁惡意洗版與重複投稿：
    禁止在短時間內連續傳送相同或高度相似之文章，或意圖利用大量留言進行洗版攻擊。違者經系統偵測，該 IP 位址將可能被永久封鎖。
  3. 禁止人身攻擊與霸凌言論：
    嚴禁發布包含公然侮辱、惡意毀謗、恐嚇威脅、歧視性言論（包含種族、性別、外貌、信仰等），或針對特定個人、社團進行集體霸凌與帶風向攻擊之內容。
  4. 個人隱私與個資保護（保護隱私）：
    禁止公開揭露任何人之真實姓名、住址、私人聯絡電話、社群帳號（如 IG/FB）、私人照片，或具特定辨識度之個資。系統將自動強制進行遮罩去敏。
  5. 遵守法律規範與智慧財產權：
    嚴禁散布猥褻色情、暴力血腥、毒品賭博、詐欺廣告或任何違法之文字與圖片。轉載非原創內容請註明出處，切勿侵犯他人著作權。
  6. 版主審核裁量權：
    管理團隊保有最終審核與裁決權，若投稿內容有爭議或違反校園和諧，版主有權直接退回或刪除，恕不另行通知。

1. 言論立場免責：本平台為提供校園資訊交流之開放性匿名投稿系統，刊載之所有內容（包含文字、圖片、連結等）均為投稿者個人立場，並不代表本平台管理團隊或松山工農官方之立場或觀點。

2. 法律責任歸屬：網路匿名性並不保障違法行為免責。依據中華民國法律，發表言論仍須承擔相應之刑事與民事責任（包含但不限於刑法妨害名譽罪、公然侮辱罪、個人資料保護法等）。如貼文涉及重大違法情事，本平台將依據合法程序配合司法檢調機關或校方調查，提供必要的登入資訊與紀錄（包含 IP 位址）。

4. 服務中斷免責：本平台不對因伺服器故障、網路連線異常、系統維護或不可抗力因素所導致之訊息遺失、儲存失敗或服務中斷負擔任何損害賠償責任。
